# Bundle code (Step 7)

This folder holds `opensky_bundle`, the reference **Declarative Automation Bundle** for
[Step 7](../../docs/52-dabs.md). It deploys `opensky_pipeline` (Step 5) and `opensky_job` (Step 6):

```text
opensky_bundle/
├── databricks.yml                         # variables catalog/schema, dev and prod targets
├── resources/
│   ├── opensky_pipeline.pipeline.yml      # serverless SDP pipeline
│   └── opensky_job.job.yml                # hourly: pipeline task → post_process notebook
└── src/
    ├── opensky_pipeline/transformations/  # bronze / silver / gold, as generated by Genie Code
    └── post_process.py                    # task 2: prints gold row counts
```

The pipeline source is the code Genie Code generated for the tutorial; the YAML and the
post-process notebook were written by hand.

## Deploy from the workspace (no CLI)

1. **Workspace** → **Create** → **Git folder** → `https://github.com/databricks/tmm`, with
   **Sparse checkout mode** and the cone pattern `DSDE-Genie-Tutorial/code/dabs`.
2. Open `opensky_bundle`, set `catalog` / `schema` in `databricks.yml` (default `workspace.default`).
3. **Deployments** → `dev` → **Deploy**, then run `opensky_job` from **Bundle resources**.

## Deploy from a laptop (CLI)

```bash
cd DSDE-Genie-Tutorial/code/dabs/opensky_bundle
databricks bundle validate --profile <profile>
databricks bundle deploy   --profile <profile> --var schema=<your_schema>
databricks bundle run opensky_job --profile <profile> --var schema=<your_schema>
```
