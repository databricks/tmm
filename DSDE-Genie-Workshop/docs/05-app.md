# 5. Databricks App with Genie Code — a 3D APAC flight map

## What we do

We build an interactive **3D visualization** with **Databricks Apps** — a way to host web apps
right next to your data, with governed access and no separate infrastructure to manage. The whole
app is **generated by Genie Code** from a single natural-language prompt: a React/TypeScript app
that uses **deck.gl** to draw each flight's trajectory as a 3D path — following its real altitude —
that you can zoom, pan and rotate.

It reads the raw Marketplace table directly and filters to an **APAC bounding box**, so this step
stands on its own and doesn't depend on the pipeline's gold tables from [Step 4](04-pipeline.md).

## Step-by-step guide

> **Step 1: Open Genie Code**
>
> Create a new **Databricks App** and open **Genie Code**.
>
> **Step 2: Generate the app**
>
> Give it this prompt:
>
> ```text
> Create a Databricks App (React + TypeScript) that shows a 3D, zoomable map of
> APAC flight trajectories, using deck.gl for rendering.
>
> Data: query marketplace.opensky.state_vectors directly. Keep only airborne
> rows (on_ground = false) inside the APAC bounding box (latitude between -50
> and 60, longitude between 60 and 180) whose time_position falls between 12:00
> and 12:15 on 2026-03-01, and drop bad rows (null latitude/longitude, or
> geo_altitude outside 0-20000 m). Pick the 100 callsigns with the most
> position reports.
>
> For each of those 100 flights, order its positions by time and draw the
> trajectory as a 3D path that follows the aircraft's altitude (use
> geo_altitude as the elevation), colored by altitude. Give the map a pitched
> 3D view the user can zoom, pan and rotate, and show a tooltip on hover with
> the callsign, altitude in feet and speed in knots.
> ```
>
> **Step 3: Connect the data**
>
> Point the app at your **SQL warehouse** and the Marketplace table
> `marketplace.opensky.state_vectors` from [Step 1](01-marketplace.md). No pipeline output is
> needed — the app applies the APAC bounding box itself.
>
> **Step 4: Deploy**
>
> Save a copy of the generated app in `code/app/`, then deploy and open it.

> [!TIP]
> **Feature spotlight — Generate whole assets**
>
> **Generate whole assets** — the same Genie Code capability from [Step 4](04-pipeline.md), now producing a
> *different* asset type: one prompt yields a complete, deployable Databricks App, not just a
> code snippet.

## Recap

You have a live, **3D** zoomable map of APAC flight trajectories — 100 flights drawn at their real
altitudes — generated end-to-end by **Genie Code** from one prompt, reading the Marketplace data
directly. The payoff of the whole workflow.
